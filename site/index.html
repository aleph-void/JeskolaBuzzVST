Buzz Machines,
in Any VST3 DAW

BuzzBridge loads classic Jeskola Buzz generator and effect DLLs and runs them as automatable VST3 instruments and effects — on Windows natively, and on Linux through WINE and yabridge.

// Features

One Bundle, Two Plugins

BuzzBridge ships as a single VST3 bundle exposing Buzz Generator Bridge for instruments and Buzz Effect Bridge for effects.

🎛

Automatable Parameters

Every Buzz machine parameter is mapped to a VST3 slider with its real name, range, and default.

🎹

Full MIDI Support

Notes, velocity, CC (with MIDI Learn), and poly pressure are translated into Buzz's native note and control format.

🌉

32 & 64-bit DAWs

64-bit hosts load machines through an out-of-process 32-bit bridge with shared-memory audio. A buggy machine can't take down your DAW.

🐧

Linux via yabridge

A cross-compiled build runs in Bitwig, Reaper, Ardour, Renoise and others through WINE and yabridge, with a one-step installer.

📦

Machine Database

An optional archive of 726 Buzz machines is published with each release, ready to drop into your Gear folder.

🔏

Signed Windows Builds

Windows binaries and the installer are code-signed, and the installer registers a standard uninstaller.

// Getting Started

Install & Play

You'll need some Buzz machine DLLs — grab the machine database from the release, or point BuzzBridge at your existing Buzz Gear folder.

  1. Install. On Windows, run the setup .exe. On Linux, extract the tarball and run the bundled installer: 
    tar xf BuzzBridge-Linux-vX.Y.Z.tar.gz
cd BuzzBridge-Linux-vX.Y.Z
./installer.sh
    The Linux installer needs yabridge and offers to install WINE with 32-bit support.
  2. Load a bridge. Add Buzz Generator Bridge as an instrument or Buzz Effect Bridge as an effect in your DAW.
  3. Pick a machine. Open the plugin editor, choose a gear folder, and load a Buzz machine DLL.
  4. Play. Parameters appear as automatable sliders. For generators, send MIDI notes — velocity is routed to the machine's volume parameter.

Building from source, the bridge architecture, and Linux troubleshooting are covered in the README.
